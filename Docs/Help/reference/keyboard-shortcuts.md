# Keyboard Shortcuts

A few shortcuts act on the focused seat while the [Wheelhouses](../tutorials/wheelhouses.md) tab is open; they are marked *On the Wheelhouse stage*, and listed together at the end.

## Window & Application

| Shortcut | Action |
|---|---|
| **⌘,** | Open Settings |
| **⌘W** | Close window (keeps app running, preserves sessions) |
| **⌘⇧W** | Close current tab |
| **⌘Q** | Quit (confirmation shown if Direct sessions are running) |
| **⌘M** | Minimise window |
| **⌘H** | Hide application |
| **⌘?** | Open Help |

## Terminal Management

| Shortcut | Action |
|---|---|
| **⌘N** | New terminal (with dialog) |
| **⌘T** | Quick new terminal in same column and working directory. *On the Wheelhouse stage:* a Quick Terminal for the focused seat |
| **⌘⇧N** | New column |
| **⌘⌫** | Delete current terminal (moves to bin). *On the Wheelhouse stage:* close the focused pane |
| **⌘⇧⌫** | Open bin |

## Navigation

| Shortcut | Action |
|---|---|
| **⌘B** | Back to board |
| **⌘1**–**⌘9** | Jump to an open terminal (on the Wheelhouse stage: to a seat, left to right) |
| **⌃⌘R** / **⌃⌘H** / **⌃⌘M** / **⌃⌘W** | Show the Repositories / Harnesses / Marketplaces / Wheelhouses sidebar tab |
| **⌘K** | Command palette |
| **⌘]** | Next pinned terminal tab |
| **⌘[** | Previous pinned terminal tab |

## View & Search

| Shortcut | Action |
|---|---|
| **⌘⌥Z** | Toggle zoom mode. *On the Wheelhouse stage:* zoom the focused pane |
| **⌘F** | Find in terminal buffer |
| **⌘⇧S** | Export session to file |

## Actions

| Shortcut | Action |
|---|---|
| **⌘D** | Toggle favourite on current terminal |
| **⌘⇧T** | Open in Terminal.app at current working directory |

## Wheelhouse stage

While the [Wheelhouses](../tutorials/wheelhouses.md) tab is open, these act on the focused seat:

| Shortcut | Action |
|---|---|
| **⌘J** | Bring up the seat that has waited longest |
| **⌘T** | New Quick Terminal for the focused seat |
| **⌘I** | The focused seat's harness details |
| **⌘P** | Keep the focused seat on stage (or stop) |
| **⌘⌫** | Close the focused pane (a seat whose harness still runs only leaves the stage) |
| **⌘⌥Z** | Zoom the focused pane to fill the window, and back |
| **⌃⌘F** | Wheelhouse focus mode |
